A professional, minimalist authentication flow built with Next.js 15, TypeScript, and Tailwind CSS 4, following the sophisticated aesthetic of Claude.ai.

## ✨ Features

- **Splash Screen**: Minimalist onboarding with a soft parchment feel.
- **Responsive Flow**: Seamless transition between Splash -> Welcome -> Auth -> Home.
- **Modern UI**: Solid surfaces, refined serif/sans-serif typography, and subtle micro-animations.
- **Scalable Architecture**: Strict separation of UI components, hooks, and state management (Context API).

## 🚀 Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the development server**:
   ```bash
   npm run dev -- --port 3100
   ```

3. **Open the browser**:
   Navigate to [http://localhost:3100](http://localhost:3100).

## 🛠 Tech Stack

- **Next.js 15**: App Router architecture.
- **TypeScript**: Type-safe development.
- **Tailwind CSS 4**: Next-gen utility-first styling.
- **Framer Motion**: Smooth, refined transitions.
- **Lucide React**: Clean, minimalist iconography.
